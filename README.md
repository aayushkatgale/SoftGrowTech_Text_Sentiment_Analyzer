# SoftGrowTech_Text_Sentiment_Analyzer
A simple AI-based Text Sentiment Analyzer using Python and TextBlob to classify text as Positive, Negative, or Neutral.

# Project Overview

This project is a simple AI-based Text Sentiment Analyzer developed using Python and TextBlob.

The system accepts text from the user and analyzes its sentiment as:

- Positive
- Negative
- Neutral

# Technologies Used

- Python
- TextBlob
- Natural Language Processing 

# Features

- Accepts user input text
- Analyzes the sentiment of the text
- Classifies the text as Positive, Negative, or Neutral
- Displays the predicted sentiment
